# 地下管网血缘变更工作台（离线）

面向某市地下管网中心月度叠加图层场景的**纯前端离线工作台**：把测绘、阀门台账、管段拓扑、风险模型与施工许可的血缘变更在浏览器本地完成核验、求值、重算与发布审阅，并在**局部发布后**用 90 日独立核验观测验证风险模型是否漂移、是否允许扩面。技术栈为 **React 18 + TypeScript + Vite + IndexedDB + WebWorker**，无后端、无登录、断网可用。

## 0. 发布后漂移验证（本批次新增，页面⑪）

局部发布后，模型是否漂移不能只看发布前后分数，而要对**随发布快照进入评估母体的每个管段**做预测-观测配对。实现要点：

| 要求 | 实现位置 |
| --- | --- |
| 冻结发布时对三终点各自预测的未来 90 日风险概率、空间分区、模型版本 | `driftTypes.ts` 的 `FrozenSegment`；`driftSample.ts` 的 `buildFrozenCohort` |
| 风险事件 = 90 日内独立现场核验确认的属性异常 / 许可边界命中 / 维修确认（三终点） | `driftTypes.ts` 的 `DriftEndpoint`；`driftSample.ts` 的 `buildObservations` |
| **不得把人工修正、未复核、窗口未结束当阴性** | `ObservationStatus` + `UNOBSERVABLE_STATUSES`；`drift.ts` 的 `pairPredictionsWithObservations` 只纳入 `verified` 且 `event` 非空 |
| 独立复核样本账 + 已知入样概率 | `ReviewLedger` / `SelectionRecord`；`buildLedger` |
| 预测观测配对器（按终点分别配对） | `pairPredictionsWithObservations`（每终点独立配对 + 排除计数） |
| 空间校准曲线 + 校准截距/斜率（加权 Logistic + 三明治方差） | `stats.ts` 的 `fitCalibration` / `calibrationCurve` |
| Brier 误差 + 召回率及 95% 区间 | `stats.ts` 的 `brierSummary` / `recallSummary`（有效样本量 Wilson） |
| 版本差异检验（当前 vs 上一发布版本） | `drift.ts` 的 `buildVersionDifference`（配对 ΔBrier 区间 + 斜率结构反转） |
| 扩面门禁（逐终点 + 总体） | `buildEndpointGate` / `buildRouteResult`；`GATE_CONFIG` |
| 两条抽样路线对照（随机不加权 / 分层逆概率加权） | `buildRouteSelections`、`evaluateRoute`、`runDriftValidation` |

**扩面门限（三终点均须满足才可扩面）**：①每个终点都有独立观测；②关键分区（样例 `Z-H`）校准斜率 95% 区间包含 1；③总体 Brier 较上一发布版本增幅 ≤ 0.02（用配对差）；④召回率 95% 区间下限 ≥ 0.70；⑤样本内不存在未复核/人工修正/失访/窗口未结束记录。任一不满足即阻止扩面，并保留「可观测范围」说明。

### 0.1 可离线回放的虚构样例（页面⑪）

- 母体：`REL-2026-01` 发布的 **1000 段**，分区 `Z-A 420 / Z-B 380 / Z-C 160 / Z-H 40`，其中 **Z-H 为稀有高风险分区，仅 40 段（4%）**。
- 复核预算均为 **100 段**，同一三终点、同一 90 日观察窗、同一门限（告警阈值 θ=0.30，Brier 增幅 ≤0.02，召回下限 ≥0.70）。
- **路线 A（简单随机，不加权）**：每段 π=0.10，Z-H 期望仅 4 段，实际抽中 **4 段**；其关键分区召回区间跨 0.70，**阻止扩面**，并检出不可观测记录（1 未复核 + 1 人工修正 + 1 失访 + 1 窗口未结束）。
- **路线 B（关键分区全纳 + 逆概率加权）**：Z-H 全部 40 段纳入（π=1），其余 960 段随机 60 段（π=60/960≈0.0625，权重≈16），按 1/π 还原同一母体；三终点均通过门禁，**可扩面**。

因此样例证明：相同预算与门限下，**随机抽检代表性直接但稀有分区收敛慢、区间跨门限**；**分层加权让关键分区证据更快积累且总体指标可还原母体**，但必须记录每段入样概率、检查失访与可观测性。

## 1. 能力与需求对应


| 需求 | 实现位置 |

## 2. 虚构样例数据（可重复运行，无随机数）

定义于 `src/domain/sampleData.ts`，两个相邻瓦片 `TILE_A`/`TILE_B`（分界 x=100）：

- **基准月包 `PKG-2026-01`**：6 个管段（S1–S6，S4 跨瓦片）、2 个阀门（V1 开、V2 关）、2 个控制点（CP1/CP2）、许可 `PRM-2026-001`（3 米施工缓冲，工程期 2026-03-01 至 2026-09-30，获批对象 S3）、风险模型 `RM-CONN`（连通特征，阈值 0.7，水位 2.5 米）。
- **控制点改正包 `PKG-2026-02`**：Z-A 分区整体平移约 **0.81 米**，S3 向许可缓冲外沿移动；95% 误差带半宽约 1.55 米，S3 缓冲外沿剩余净距约 0.5 米（未穿越但误差带触及）→ **许可进入复核并阻断该局部发布**。
- **拆并阀门包 `PKG-2026-03`**：跨瓦片管段 S4 拆为 `S4A`/`S4B`，新阀门 `V3` 在瓦片分界接入邻瓦片；切片闭包经 V3 扩展到两瓦片，连通特征指纹改变触发模型重算；组合许可种子后闭包覆盖整包，切片按规则扩大至整包。全链路线给出相同新拓扑与许可判定，仅重建范围不同。
- **异常补测包 `PKG-BAD-09`**：测量历元缺失、单位误标（坐标为米量级却声明厘米）、历史管段 S77 两个等距候选无法唯一续接；即使 SHA-256 正确仍被语义核验阻断，不产生校正/拓扑/快照。

## 3. 本地启动

### 3.1 开发模式（Node 22，已在当前环境验证）

```bash
npm install          # 如全局 npm 缓存无权限，可加 --cache ./.npm-cache
npm run dev          # http://localhost:5173
npm run build        # 类型检查 + 生产构建到 dist/
npm run preview      # 本地预览生产构建 http://localhost:4173
npm test             # vitest 单测（39 个用例）
```

### 3.2 Docker / Compose（一键启动，nginx 托管静态资源）

```bash
docker compose up --build
# 打开 http://localhost:8080
```

Dockerfile 为多阶段构建（node:22-alpine 构建 → nginx:1.27-alpine 托管），含 SPA 回退与 gzip 配置。

### 3.3 账号说明

本应用为**纯离线单用户工具，没有登录体系和服务端账号**。打开即用；发布审阅页默认审阅人身份为「审阅人-张工」，可在界面中修改，审阅草案连同身份保存在本地 IndexedDB。第⑩页的“服务器发布版本”为内置的模拟同步端点，用于演示冲突合并规则。

## 4. 推荐验证路径（与题目叙事一致）

1. 页面①选择「切片重算」，依次导入四个来源包；观察异常包出现三条 block 语义问题且无后续产物。
2. 页面②查看 CP1/CP2 残差、Z-A 的 95% 误差带与 Z-B 的“继承全局”标注，地图上灰色虚线为上一版本几何。
3. 页面③确认 `PKG-2026-03` 中 S4 → S4A+S4B 的拆分关系及共点测量证据。
4. 页面④确认 V3 阀门节点属于 TILE_B、跨瓦片依赖 `TILE_A → TILE_B via S4A/V3`。
5. 页面⑤/⑦确认 `PKG-2026-02` 许可判定为 **review（复核）**、阻断原因指向 PRM-2026-001；`PKG-2026-03` 闭包同时包含两瓦片管段。
6. 页面⑧点击“运行切片 vs 全链对照”，两路线拓扑签名与许可判定一致；窄种子（如仅 S3）时切片只重算 1 条管段并保留 6 条原发布引用。
7. 页面⑨对快照执行“回放快照”，回放指纹一致；阻断快照保留全部阻断原因，禁止发布。
8. 页面⑩先“模拟离线规则更新”，回到⑦看到历史报告标记失效；再“模拟服务器发布版本前进”，保存一条指向服务器终态发布的草案后执行同步，观察其被列为冲突且不覆盖服务器版本。
9. 页面⑪点击“运行漂移验证（离线样例）”：先看两路线对比表——路线 A 的 Z-H 关键分区仅 4 段、召回区间跨 0.70 且斜率不含 1，路线 B 的 Z-H 全部 40 段、召回区间下限 ≥0.70、斜率区间含 1；再看门禁逐条与阻断原因（路线 A 阻止扩面、8 项，路线 B 可扩面），并核对“不可观测记录”表（未复核/人工修正/失访/窗口未结束均未计入阴性）。调整告警阈值 θ 后重跑，确认报告指纹随口径变化。
10. 断网后刷新页面，IndexedDB 中台账、快照、草案、漂移报告仍然可读。
